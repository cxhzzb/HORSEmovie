**合计约 65 GB。** 这是迁移里唯一"重"的部分，其余全是几 MB 的文本和脚本。

放在 `~/ComfyUI/models/<类别>/<文件名>`。文件名**必须完全一致**——工作流里写死了这些名字。

## ⚠️ 关于"⚠️"那几个

工作流里引用的这几个是 **int8 / convrot 量化版**，文件名带 `_int8_convrot` 或 `-UC-int8`。
Comfy-Org 官方仓库提供的是 **fp16 / nvfp4** 版本，**文件名对不上**。两种情况：

**情况 A：能拿到同名文件（推荐）**
直接拷过去最省事。这几 个文件在本机就有：
```bash
ls -lh ~/ComfyUI/models/diffusion_models/Minimax_H3/
ls -lh ~/ComfyUI/models/text_encoders/ | grep -i minimax
ls -lh ~/ComfyUI/models/loras/ | grep -i turbo
```
用移动硬盘或局域网直接拷，65 GB 走 USB3 大约 10–20 分钟。

**情况 B：拿不到，改用官方版本**
下载官方文件后，**工作流里的模型名要改**。两种做法：
1. 在 ComfyUI 界面里手动选一遍模型，另存为新工作流，再把 `pipelines.json` 里的 workflow 名改掉；
2. 或者用 `comfy.py run --set '#节点.unet_name="新文件名"'` 在运行时覆盖（不改用户的工作流文件）。

⚠️ 换成 fp16/nvfp4 后**显存占用会变**。nvfp4 在 RTX 40 系上没有硬件加速（实测文本编码器换 nvfp4→int8 耗时无变化），
但 fp16 的 32B 文本编码器**很可能放不进 8G 显存**，届时整个方案的可行性要重估。

python3 doctor.py          # 在本 bundle 目录里跑
