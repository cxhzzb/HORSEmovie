# 逐镜验收（每一镜都要过，不许跳）

> Prompt 写好不等于结果对。**每一镜出片后都要过下面四道关**，任何一道不过就重出。
> 自动化脚本：`scripts/qa_shot.py`（规格 + 声音）。身份与重影必须**人工看帧**。

---

## 关卡 1：规格（可自动化）

| 检查项 | 通过标准 |
|---|---|
| 分辨率 | 与 `--megapixels` 对应（0.8 → **1216×672**） |
| 帧率 | 24 fps |
| 帧数 | **5 + 17k**，与 `dur` 对应（6 秒 → 158；8 秒 → 192） |
| 时长 | 与分镜表一致（6 秒 → 6.58s；8 秒 → 8.00s） |
| 音频流 | 存在，**32000 Hz 立体声** |
| 音轨非空 | 不是全程静音 |

```bash
ffprobe -v error -show_entries stream=width,height,nb_frames,sample_rate,channels \
        -show_entries format=duration -of default=nw=1 <file>.mp4
```

---

## 关卡 2：身份（人工看帧）

**抽帧**：至少抽 3 帧（开头 / 中段 / 结尾），**关键帧切点前后各抽一帧**。

```bash
for t in 1 4 7; do ffmpeg -v error -ss $t -i in.mp4 -frames:v 1 f$t.png -y; done
```

**对照**：把 `refs/character_<id>.png`、`<镜号>_key_*.png`（首帧）、抽出的帧并排成一张对比图。

**通过标准**：
- 是**同一个人**（骨相、发型、肤色、年龄感一致）
- 服装、道具、身体比例与首帧一致
- **左右不对称的特征没有跑边**（如"只有左小臂有鳞纹"必须仍然只在左小臂）
- 有面部特效的（星图、光纹）在成片里仍然存在，不是被抹掉

**不过就重出**：优先换 seed；仍不过则回退检查关键帧是否本身就不像。

---

## 关卡 3：重影 / 伪影（人工看帧）★

**这是最容易被漏掉的一关**——缩略图上看不出来，放大就露馅。

**通过标准**：
- 画面里**没有第二个同一个人**（重影 / 双头 / 残影）
- 没有多余的手指、肢体、错位的头
- 没有纯灰 / 纯色 / 死白方块
- 没有闪烁、跳帧、黑帧
- 没有多余人物、文字、乱码、水印、字幕卡

**已知诱因**：台词期间叠推镜/变焦。所以**先检查所有写了镜头运动又有台词的镜头**。

---

## 关卡 4：声音（可自动化 + 抽听）

用 `scripts/qa_shot.py` 生成声谱图并给出判定。

### 判据：中频活跃占比（已用真实样本标定）

「中频活跃」= 300–3400Hz 能量高于该轨自身底噪 8dB 的时间窗。

| 样本 | 活跃占比 | 判定 |
|---|---|---|
| 001 空镜（无台词） | **2%** | 无谐波活动 ✓ |
| 002 空镜（无台词） | **0%** | 无谐波活动 ✓ |
| 008（台词「……这个不是废铁。」） | **21%** | 有谐波活动 ✓ |
| 030（台词「是笼子。你们跪着活了三千年，还管它叫太平？」） | **50%** | 有谐波活动 ✓ |

阈值：**< 3% 视为"没有谐波内容"**（若预期有台词就是失败）；**> 85% 视为"疑似贯穿全片的配乐"**；
中间区间通过，并把检测到的谐波段画在审阅图上（绿色条）。

⚠️ **试过但废弃的判据**：用频谱平坦度判断"是不是浊音"。
实测语音样本落在 0.18–0.47，而一条无台词的镜头是 0.01，**不能区分**，已降级为参考信息。

### 通过标准

| 检查项 | 通过标准 |
|---|---|
| **台词** | 中频活跃占比落在 3%–85%，且有谐波段（脚本自动判定） |
| **环境声** | 低频底噪覆盖 > 60% 时长 |
| **无 BGM** | 中频活跃占比 < 85%（没有贯穿全片的连续中频能量） |

### 人工抽听（听得到时必须做）

- 语言正确（不是英文/日语）
- 台词**只读一遍**、没有被截断
- 没有串台（台词绑到了错误的角色口型上）
- 没有被环境声盖住
- 齿音/爆音不刺耳

**声谱图是证据，脚本只是提示。** 图上的绿色条应当与肉眼可见的谐波列重合；
对不上就说明判定有问题，以图为准。

## 关卡 5：戏剧（人工判断，最重要）

回到 `SKILL.md` 第 0 节的四个问题，对这一镜再问一次：

- [ ] 这一镜**在讲什么**？说得出来吗？
- [ ] 台词是不是这一镜真正该说的？删掉它这一镜还成立吗（成立就该删）？
- [ ] 动作的**起点和终点**清楚吗（状态有没有变化）？
- [ ] 和前后的衔接：上一镜结束的状态 = 这一镜开始的状态吗？

**这一关不过，前面四关全过也没用**——那就是"45 个各自成立的画面"。

## 全片验收

```bash
cd ~/.dsh/skills/comfyui
$PY assemble.py --project <项目> --check --sheet --concat
```

- `--check`：逐镜核对规格，列出缺失与异常
- `--sheet`：每镜取中间帧拼成审阅表（一眼看完整片）
- `--concat`：按镜号拼接粗剪（规格不一致会自动重编码）

**连续性检查**（人工看审阅表）：
- [ ] 同一角色跨镜是不是同一个人
- [ ] 镜头轴线有没有无缘无故反转
- [ ] 情绪曲线是否连续（不是忽高忽低）
- [ ] 声音有没有硬断或重复起句
- [ ] 总时长是否与目标一致
